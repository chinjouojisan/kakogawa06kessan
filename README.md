# 加古川市 決算チャレンジ

加古川市の令和6年度一般会計決算（982億円）を題材にした、市民向けの予算編成シミュレーションです。案内役はカコモ（加古川生まれの水の精霊執事・非公式キャラクター）。

## 公開URL
https://chinjouojisan.github.io/kakogawa06kessan/

## ファイル構成
- `index.html` … 本体（単一HTML。React + Babel をCDNから読み込み）
- `ogp.jpg` … SNSシェア用サムネイル（1200×630）
- `favicon.ico` / `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` … アイコン
- `manifest.json` … ホーム画面追加（PWA）用

## 収録内容
- 全196事業の決算額・方向性
- カコモの視点（全196事業。議会記録のある87事業は個別執筆）
- 議員の実際の質疑（決算審査の委員会記録より）
